# webProject
Реализация "интересных" алгоритмов:
1. А*
   Задается размер поля (n), далее генериуется карта-лабиринт размером n*n, лабиринт можно модернизировать, добавляя/убавляя непроходимые клетки. После чего запускается алгоритм и отрисовыается анимация поиска и прохождения пути на каждой итерации алгоритма в режиме реального времени.
   
3. Алгоритм кластеризации
   Генерируется плоскость, на которой можно расставить точки, а также выбирается количество кластеров. После чего с помощью алгоритмов кластеризации определяются кластеры и выделяются определенным способом.
   В программе использовалось три различных алгоритма кластеризации:
   1) К-средних - кластеры образованы цветами.
   2) Иерархический - кластеры образованы типом раскраски.
   3) Алгоритм минимального покрывающего дерева - кластеры образованы линиями.
      
4. Генетический алгоритм
   Генерируется плоскость, на которой можно расставить точки. После чего с помощью генетического алгоритма ищется самый лучший путь. В процессе поиска показывается лучший путь на данный момент.
   
5. Муравьиный алгоритм
   Генерируется плоскость, на которой можно расставить точки. После чего с помощью муравьиного алгоритма ищется самый лучший путь. В процессе поиска показывается лучший путь на данный момент.
   
6. Нейронная сеть
   Реализована нейронная сеть, которая работает с пиксельными изображениями 50 на 50 пикселей. На плоскости рисуем цифру за счёт закрашивания пикселей, нейронная сеть определяет нарисованную цифру.

В работе использовались базовые HTML, JavaScript и CSS, для реализации нейронной сети - Python.
